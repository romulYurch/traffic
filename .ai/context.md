# traffic.lk — контекст проекта

## Стадия и правила игры

- **Разработчик один, аудитории нет, стадия — ранняя разработка.** Никакой обратной
  совместимости: форматы данных, API классов, структуру карты можно ломать свободно.
  Не нужны миграции, фича-флаги, депрекейшены, «оставим старое на всякий случай».
- Мёртвый код не копить: заменили подход — старый удаляем, история есть в git.
- Коммитит пользователь сам. Сообщения коммитов — по-русски, коротко, как в истории.
- Язык общения и рассуждений — русский; имена из кода не переводить.
- Отвечать кратко, без пересказа очевидного.

## Окружение

- Сайт: **https://traffic.lk** (OpenServer), корень сайта — `www/public/`.
  `index.html` подключает ресурсы абсолютными путями (`/dist/build.js`, `/css/...`),
  поэтому открывать надо через сервер, а не файлом с диска.
- Git-репозиторий — `www/` (remote `github.com/romulYurch/traffic`). Папка
  `traffic.lk/` выше — не под git (там только `.idea`).
- Сборка: в `www/` → `npm run build` (webpack 5, `mode: development`, source-map).
  Вход `public/js/traffic.js` → `public/dist/build.js`. `dist/` в `.gitignore`.
  Для разработки удобно `npx webpack --watch`.
- **После правки JS без пересборки ничего не изменится** — браузер грузит только бандл.
- jQuery и `jquery-mousewheel` подключаются через `ProvidePlugin` (глобальные `$`).
- Node 18.

## Модель мира

- Мировые координаты в пикселях, 20 px = одна полоса = 5 м (`pix2m = 0.25`).
  Экранные = мировые × `viewport.zoom` + `viewport.leftTop`
  (`Number.prototype.zoom/toScreenX/toScreenY`, `Point2d.toDraw`).
- Иерархия: **Road → dirs {1, -1} → Lane → Section**. Дорога прямая
  (горизонтальная или вертикальная), у неё одно или два направления.
- **Section** — квадрат `size×size` с центром `center`. Направление `dir` —
  единичный `Point2d`. `rightDir`/`leftDir` — поворот `dir` на ±90° (ось Y вниз,
  поэтому `+π/2` — это «направо» для водителя).
- Связи секции: `next`/`prev` — вдоль полосы; `right`/`left` — соседи в той же
  дороге (у встречной полосы «лево» зеркальное); `crossSection` — куда можно
  свернуть с этой секции; `crossInSection` — откуда сворачивают на неё.
- Счётчики: `rightCnt` — полос справа, `leftCnt` — попутных слева,
  `sepCnt` — встречных.
- Перекрёстки ищет `ViewPort.initRoads`: секции **разных** дорог с совпадающим
  центром. Направление поворота (с m на n или с n на m) решает правило
  «хватает ли полосы после поворота с учётом `rightCnt`/`leftCnt`».
  Подробно — скил `geometry.md`.

## Игровой цикл

`ViewPort.init` → `initRoads` → (`initVehicles`) → `setInterval(updateContent, 30 мс)`.
Каждый тик: `vehicle.updatePos()` для всех → удаление `unusable` и спавн новой →
`drawContent()`: очистка, секции (спрайты), разметка, машины. Кадр перерисовывается
целиком, отдельного слоя для статики нет.

## Стиль кода

- Табы, фигурные скобки на новой строке (Allman), ES6-классы, `export default class`.
- Разделители методов `//****************************************`.
- Комментарии — по-русски или по-английски, как в соседнем коде.
- Имена файлов исторически с опечатками (`veiwport.js`, `mouseSmothMove.js`) —
  при переименовании поправить все импорты.

## Проверка изменений

1. `npm run build` в `www/` — должен собраться без ошибок.
2. Открыть https://traffic.lk во встроенном браузере, посмотреть консоль и картинку.
3. Клик по секции включает её отладку (обводка + `road, lane, section`) —
   `ViewPort.debugSections`. У машин `debug = true` в конструкторе: красная рамка —
   текущая секция, синяя — граница видимости, зелёная/жёлтая — запланированный поворот.
4. Объекты карты в консоли не видны (нет глобалей). Для отладки временно вешать
   `window.vp = viewPort` в `traffic.js` и не коммитить.
