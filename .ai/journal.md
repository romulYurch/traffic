## 2026-09-25 — возвращение к проекту, аудит, заведён `.ai/`

- Проект не трогали с марта 2022. Жалоба: «после перехода на ООП перестал работать».
- Проверка: сборка на webpack 5 проходит, в консоли ошибок нет, дороги и перекрёстки
  строятся. Если включить машины, они ездят, поворачивают и тормозят. **Объектная модель
  рабочая.** Ощущение поломки дают три вещи:
  1. машины выключены (`//this.initVehicles()`) — по словам автора, из-за проблем
     с разметкой;
  2. канвас по высоте около 150 px из-за `$(document).height()`;
  3. без `npm run build` и сервера с корнем в `www/public/` страница не работает вообще.
- В рабочей копии лежит незакоммиченное обновление зависимостей: webpack 4→5,
  webpack-cli 3→5, jQuery ^3.4.1→3.7.1. Сборка с ним проходит.
- Заведена инфраструктура знаний по образцу fortexgroup.lk, упрощённая под соло-проект:
  `www/CLAUDE.md` (подключает `.ai/context.md`), скилы `geometry` / `markings` /
  `vehicles`, `todo.md`, этот журнал. Из Fortex не переносили маркер загрузки контекста,
  fallback для Project Knowledge, машинные файлы, агентов и Битрикс: здесь один человек,
  одна машина и только Claude Code.
- Сайт: https://traffic.lk.
