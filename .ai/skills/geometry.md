# Геометрия дорог

Как из описания карты получаются секции и связи между ними. Разметка — отдельный скил
`markings.md`, машины — `vehicles.md`.

## Описание карты

`maps/test_map.js` → `testRoads(width, height, laneSize, laneImg)` возвращает массив `Road`.
Дорога собирается так:

```js
roadDir.push({ dir: -1, lanes: [ { start, end, size, img }, ... ] });
roadDir.push({ dir:  1, lanes: [ ... ] });
roads.push(new Road(roadDir, roads.length));
```

- `start`/`end` — центры крайних секций полосы (`Point2d`). Порядок не важен:
  `Lane` сама переставит их так, чтобы движение шло от `start` к `end`.
- `dir: 1` — движение в сторону роста координаты (→ или ↓), `dir: -1` — обратно.
- Тип полосы (`v`/`h`) определяется по `start.x == end.x`. Только прямые, без диагоналей.
- **Длина полосы обязана быть кратна `size`.** `Lane.initSections` шагает от `start`
  на `size`, пока точка не совпадёт с `end` через `eq`. Если не кратна — бесконечный цикл
  и зависшая вкладка.
- Порядок полос внутри направления задаёт `lane.num` (индекс в массиве). Сейчас от него
  зависит только старт цикла разметки (`1 + this.num`), см. `markings.md`.

## Section: направления

`section.js`, конструктор:

- `corner` — угол `dir` (0, π/2, π, −π/2).
- `rightDir` — `dir`, повёрнутый на +π/2. Ось Y смотрит вниз, поэтому это «направо»
  с точки зрения водителя. `leftDir = -rightDir`.
- Все направления округляются `Math.round`, так что это всегда целые единичные векторы
  и их можно сравнивать через `eq`.

## Road: соседи и счётчики полос

`Road.initSectionSiblings` для каждой пары полос одной дороги ищет секции, у которых центр
смещён на `rightDir * size` или `leftDir * size`.

- Попутные полосы: если B справа от A, то A слева от B.
- Встречные полосы касаются **левыми** сторонами: если B слева от A и направления разные,
  то и A слева от B.

`calcSectionSiblingsCnt`:
- `rightCnt` — сколько полос справа (идём по `.right`);
- `leftCnt` — сколько попутных полос слева;
- `sepCnt` — сколько встречных. На встречке «дальше от нас» — это её `.right`, поэтому
  после пересечения разделителя цикл переключается с `.left` на `.right`.

Соседи ищутся только **внутри одной дороги**. Секции разных дорог связываются только
через перекрёстки.

## Перекрёстки: `ViewPort.initRoads`

Перебираются все пары секций разных дорог (`i < j`). Для каждой пары с совпадающим
`center` определяется, кто в кого поворачивает.

Пусть `m` — секция дороги i, `n` — дороги j:

1. Если `m.rightDir == n.dir` (с `m` направо получается направление `n`):
   - `n + m.rightCnt < длина полосы n − 1` — после поворота есть куда ехать →
     поворот **с m на n**: `m.crossSection = n`, `n.crossInSection = m`;
   - иначе полоса `n` тут кончается → поворот **с n на m**.
2. То же для `leftDir` с `leftCnt`.
3. Затем та же проверка с точки зрения `n`. Она может перезаписать результат шагов 1–2.

Заполняются поля `crossDir`, `crossLane`, `crossSectionNum`, `crossSection` (поворот
отсюда) и `crossIn*` (поворот сюда).

Ограничения текущей модели:
- **У секции один `crossSection`.** С одной клетки нельзя повернуть и налево, и направо,
  или в две разные дороги. Сложный перекрёсток требует смены модели.
- Прямо через перекрёсток едут по `next`, поворот — отдельное решение машины.
- Поиск идёт за O(секций²). На тестовой карте это нормально, на большой — будет медленно.
  Лечится индексом по `center` (Map с ключом `"x,y"`).
- Изгиб дороги (например, угол кольца) тоже оформлен как «перекрёсток» двух дорог:
  конец одной полосы совпадает с началом другой. Разметка отличает изгиб от перекрёстка
  по номерам секций (см. `markings.md`).

## Размер карты

`mapWidth/mapHeight` = максимальные координаты центров секций + `laneSize / 2`.
На них опираются ограничения прокрутки в `MouseSmoothMove.changeLeftTop`.
